# 4-ping-pong
atau disebut juga **Ping-Pong-Machine** adalah proyek PBL kelompok 4 kelas TMJ 5A.

1.**ESP32-2** atau ESP2 adalah kode ino yang berfungsi dalam mengatur mesin ping pong itu sendiri, seperti servo, gearbox, relay, dan lainnya.\
2.**ESP32-1** ESP32 pertama yang khusus menangani Web Server, Captive Portal, dan endpoint API untuk web dashboard.
3.**index.html** adalah file utama yang menampilkan seluruh antarmuka visual ke layar pengguna, mulai dari login, kontrol hingga pemantauan QoS.\
4.**style.css** adalah file yang berfungsi untuk mempercantik tampilan visual dari index.html (berisikian warna, layout, ukuran font dll).\
5.**script.js (dari sisi front end)** adalah file yang digunakan untuk memberikan interaksi pada web yang sudah dibuat.\
6.**api.php** : Endpoint backend utama untuk menangani logika REST API (autentikasi login/register, sesi latihan, pengaturan sistem, dan lainnya).\
7.**config.php** : File konfigurasi koneksi database MariaDB / Laragon.\
8.**register.php** : Script tambahan untuk memproses pendaftaran akun pengguna di sisi server.\
9.**settings.json** : File konfigurasi lokal untuk menyimpan mode, kecepatan, dan interval mesin.
